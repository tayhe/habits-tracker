🐟 收益怎么算？

1️⃣ 每个任务都有一个「每周最低次数」，叫做达标门槛
2️⃣ 一周内完成次数 ≥ 达标门槛 = 达标，收益 = 单次收益 × 实际完成次数
3️⃣ 一周内完成次数 < 达标门槛 = 未达标，收益 = 0
例：「英语背诵」单次收益 1.0，达标门槛 1次/周
✅ 本周完成 2 次 → 达标 → 收益 = 1.0 × 2 = 2.0 鱼干
❌ 本周完成 0 次 → 未达标 → 收益 = 0
例：「英语单词」单次收益 0.1，达标门槛 5次/周
❌ 本周完成 3 次 → 未达标 → 收益 = 0
✅ 本周完成 5 次 → 达标 → 收益 = 0.1 × 5 = 0.5 鱼干
🌟 本周完成 7 次 → 达标 → 收益 = 0.1 × 7 = 0.7 鱼干（多做多得！）
💡 小技巧：达标之后每多做一次都能多赚鱼干哦！
